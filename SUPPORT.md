# Support

## Bugs and unexpected behavior

Open a [GitHub issue](https://github.com/otua-protocol/otua-protocol/issues) using the Bug Report template.

Include: what you expected, what happened, steps to reproduce, environment details.

## Documentation problems

Open a GitHub issue using the Documentation Issue template.

## Implementation questions

For questions about how to implement something against the OTUA Protocol, open a GitHub Discussion (if Discussions are enabled) or a GitHub issue using the Task template.

## Security vulnerabilities

**Do not use the public issue tracker.** See [SECURITY.md](./SECURITY.md) for how to report vulnerabilities privately.

## Protocol design questions

For questions about protocol design decisions or proposals, open a GitHub issue using the Protocol / Design Proposal template and reference the relevant specification section.
