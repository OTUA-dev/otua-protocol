# @otua/config

Shared configuration utilities for the OTUA Protocol monorepo.

## Status

Foundation phase — intentionally minimal.

Configuration helpers (environment parsing, network configuration, feature flags, etc.) will be added as the application layer is built out in future phases.

## Development

```sh
pnpm --filter @otua/config build
pnpm --filter @otua/config typecheck
pnpm --filter @otua/config test
```
